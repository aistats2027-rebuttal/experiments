We train and test ADMM-DAD on 2 real-world image datasets: CIFAR10 and IXI (MRI images). We alternate the number of layers L, the attack budgets ε and τ, and examine both unbalanced and balanced regimes, with varying number of clients K and local sample sizes s_k, k=1,...,K.

We report the aggregated attacked and clean client losses, evaluated on test data, and the empirical robust generalization error, defined as the difference between the aggregated, train and test, attacked client losses.

Experimental results are found in the pdfs ``cifar10_errors`` and ``IXI_errors``.
