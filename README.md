We train and test ADMM-DAD on 2 real-world image datasets: CIFAR10 and IXI (MRI images). We alternate the number of layers L, the attack budgets ε and τ, and examine both unbalanced and balanced regimes, with varying number of clients K and local sample sizes s_k, k=1,...,K.

Experimental results are found in the folders ``CIFAR10`` and ``IXI``.
